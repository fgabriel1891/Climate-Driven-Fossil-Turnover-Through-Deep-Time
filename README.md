# Climate change shape the deep-time assembly of biological diversity

This repository contains the occurrence data, spatial regions, R analysis code, and figure renderers used for the manuscript's generalized dissimilarity models (GDMs). Bristol BRIDGE climate files are retrieved directly from the source archive by `download_climate.R`; they are excluded from Git. Run commands from the repository root. The entry point `run_review.R` prepares the data, fits the models, writes summary tables, and renders the analytical figures. It does not download data or install packages.

## Requirements

R with `ncdf4`, `terra`, `sf`, `palaeoverse`, `dplyr`, `h3jsr`, `betapart`, `gdm`, `ggplot2`, `patchwork`, `vegan`, and `rnaturalearth`. Geographic libraries required by `sf` and `terra` must also be available. The analysis has not been run from this packaged copy; package versions should be recorded with `sessionInfo()` on the reviewing machine.

## Run

```r
setwd("path/to/Climate-Driven-Fossil-Turnover-Through-Deep-Time")
source("download_climate.R")
source("run_review.R")
```

The script writes intermediate RDS files to `outputs/data`, summary CSV files to `outputs/tables`, and figures to renderer-specific `output` folders. It can take substantial time and memory because all eligible assemblage pairs are modelled. To rerun after partial output exists, remove incomplete generated outputs or set `cfg$overwrite <- TRUE` in `run_review.R`.

## Inputs and analysis

- `DATA/NOW_filtered_by_Shan_Oct2019.csv` is the archived occurrence extract. `DATA/build_now_master.R` generates the included `DATA/NOW_master_with_diet.csv` using genus-level consensus of NOW `DIET_2` values.
- `DATA/regions_gridded/` contains the study-region polygons.
- `download_climate.R` retrieves 117 annual and monthly Bristol BRIDGE NetCDF files for eight Neogene stages and the preceding Chattian baseline into `DATA/climate/raw/`. It validates required variables, skips valid existing files, and records URLs, sizes, and MD5 checksums in `DATA/climate/download_manifest.csv`. `config/stages.csv` defines stage boundaries and simulation codes. Download requires network access and archive availability.
- `R/` contains fossil and climate preparation, assemblage construction, pairwise Simpson turnover, GDM fitting, summary tables, and shared publication data.
- Figure directories contain renderers for Figures 1–5 and supplementary climate, prediction, spline, temporal, and spatial-sensitivity figures. `figure_style/` holds their shared plotting style.

At each of four H3 spatial resolutions (H0–H3), models are fit separately for Europe and North America and for all mammals, herbivores, and carnivores, with and without geographic distance. Six climate predictors describe stage mean temperature and precipitation, incoming signed changes, and changes in monthly seasonal patterns. Geological age, stage duration, and locality sampling are also included. See the manuscript methods for definitions and interpretation.

`reference_assets/` holds four cited visual assets supplied with the manuscript. These files are for figure comparison; they are not model inputs. The H3 schematic can also be generated from `fig1_conceptual/render_fig1.R`.

## Data provenance

The fossil extract is the locally archived October 2019 NOW export. Climate NetCDF files are obtained from the University of Bristol BRIDGE archive; source URLs are reconstructed by `bristol_pipeline_sources()` in `R/02_prepare_climate.R`, and source checksums are recorded during download and climate preparation. Cite the data providers and software as described in the manuscript.
